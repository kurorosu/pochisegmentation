# Archived Changelogs

このディレクトリには過去バージョンの changelog エントリをアーカイブする.

メインの `CHANGELOG.md` が長くなった際, 完了済みバージョンのエントリを minor バージョン単位でこちらへ移す.

## Files

| File | Versions |
|---|---|
| `0.1.x.md` | 0.1.0 - 0.1.x |

## How to Archive

1. `CHANGELOG.md` から該当バージョンのエントリを切り出す (`[Unreleased]` と最新リリースは残す)
2. `X.Y.x.md` 形式の新規ファイルを作成する (例: `1.3.x.md`)
3. 切り出したエントリを新規ファイルへ貼り付ける
4. 上記の表を更新する
